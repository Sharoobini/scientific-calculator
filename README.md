# 🧮 Scientific Calculator

A modern and responsive Scientific Calculator Website built using HTML, CSS, and JavaScript.

This application allows users to perform basic mathematical calculations, scientific operations, and graphical calculations through a simple and user-friendly interface.

## 🚀 Features

- Basic Arithmetic Operations (Addition, Subtraction, Multiplication, Division)
- Scientific Functions (Sin, Cos, Tan, Square Root, Logarithm)
- Degree (DEG) and Radian (RAD) Modes
- Calculation History
- Dark Mode and Light Mode
- Responsive Design for Mobile, Tablet, and Desktop
- Mathematical Graph Plotting
- Calculator Memory (M+, M-, MR, MC)
- Copy Answer
- Unit Converter
- Equation Solver
- Statistics Calculator
- Multiple Graph Comparison
- Keyboard Support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Math.js
- Plotly.js
- Browser Local Storage

## 💻 How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select Open with Live Server.
6. The calculator will open in your browser.

**Note:** An internet connection is required to load Math.js and Plotly.js from their online CDNs.
